- **FolderItem.vue**：渲染文件夹内笔记（folderId===id），是与未分类互不重叠的正确实现。
- **useNoteStore.getUnsortedNotes**：`folderId===null && !isLocal` 的合法数据 helper，现仅 FolderTree 使用，保留。

整改：
- `FolderTree.vue`：`unsortedNotes` computed 原写了冗余的 `.filter(n => !n.isLocal)`（getUnsortedNotes 已排除本地），改为 `getUnsortedNotes.value.slice().sort(...)`。
